## 🔬 Key Engineering Features

### 1. Interactive Command Palette (`CommandPalette.tsx`)
* Global keyboard shortcut listener (`Cmd+K` / `Ctrl+K`) opening a terminal-style modal.
* Fuzzy search indexing across all sections, projects, case studies, and contact channels.
* Instant navigation with keyboard-only traversal (`ArrowUp`, `ArrowDown`, `Enter`, `Escape`).

### 2. Architecture Thinking Matrix (`ArchitectureThinkingSection.tsx`)
* In-depth documentation of core system engineering principles:
  * Deterministic state machines vs. stochastic generative models.
  * Low-latency WebRTC media routing vs. HTTP polling bottlenecks.
  * Data locality, caching tiers, and offline-first client synchronization.

### 3. Astra Humanis System Preview (`AstraHumanisSection.tsx`, `AstraTeaserSection.tsx`)
* Interactive architectural breakdown of ongoing research into developmental artificial cognitive architectures.

### 4. Atmospheric Visual System (`AtmosphericParticles.tsx`, `CinematicReveal.tsx`)
* Custom HTML5 Canvas particle engine rendering 60fps floating dust motes with mouse-proximity force fields.
* IntersectionObserver-driven cinematic reveal animations with zero cumulative layout shift (CLS).

## 🛠️ Tech Stack

- **Core:** React 18, TypeScript, Vite
- **Animations:** Framer Motion, HTML5 Canvas API
- **Design System:** Tailwind CSS, Radix UI Primitives, Lucide Icons, Sonner toasts
- **Navigation:** Custom Command Palette and keyboard event handlers

## 💻 Local Development

```bash
# 1. Clone repository
git clone https://github.com/mdroushanalam-astra/mdroushanalam-portfolio.git
cd mdroushanalam-portfolio

# 2. Install dependencies
npm install

# 3. Launch dev server
npm run dev
```

Open `http://localhost:5173` and press `Cmd+K` (or `Ctrl+K`) to open the interactive command palette.
