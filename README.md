# Founder | AI Entrepreneur | Ideas & Perspectives | Personal Brand Landing Page

A modern, animated personal brand landing page built with React, Vite, TypeScript, Tailwind CSS, and shadcn-ui.

## Tech Stack

- **Vite** — Fast build tool
- **React** + **TypeScript** — UI framework
- **Tailwind CSS** — Utility-first styling
- **shadcn-ui** — Accessible component library

## Getting Started

```sh
# Install dependencies
npm install

# Start the development server
npm run dev
```

## Build

```sh
npm run build
```

## Deployment

Deploy the `dist/` folder to any static hosting provider (Vercel, Netlify, etc.).
